# cppTinyThreadPool

## 目标
从零构建一个具备工程可用性的线程池（thread pool），掌握 C++ 并发编程核心能力，并通过可观测实验理解性能与正确性的权衡。

## 目录
1. 线程与并发基础认知
2. C++ 线程创建与生命周期管理
3. 数据竞争与互斥保护
4. 锁的工程化使用与死锁规避
5. 条件变量与线程通信
6. 任务抽象与结果返回
7. 阻塞队列设计
8. 线程池 V1（基础可用）
9. 线程池 V2（生命周期管理）
10. 线程池 V3（工程优化）
11. 综合复盘与扩展

---

## 协作方式

采用固定循环推进：
1. 明确当前目标与需求
2. 自主实现
3. AI 辅助分析与订正
4. 修复与优化
5. 验证通过后进入下一阶段

### AI 协作原则
AI 不用于替代实现，而用于：
- 解释并发问题（数据竞争、死锁）
- 分析性能瓶颈
- 提供测试设计建议
- 辅助定位 bug

目标：观察 race condition。

说明：第 3 节主线先完成“无锁版本 + mutex 版本”，atomic 版本作为扩展对比。

- 多线程累加计数器
- 对比：
  - 无锁版本
  - mutex 版本
  - atomic 版本（扩展）
