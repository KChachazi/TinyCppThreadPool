## 说明

下文用于说明本仓库的协作学习流程。

1. 我：学习者、提问者与主要实现者，负责根据需求完成代码与修复。
2. Copilot：指导者与审阅者，负责给出学习目标、任务要求、订正意见与验收结论。

### 协作方式

协作采用固定循环，按目录逐条推进：

1. Copilot发布当前条目的学习目标、相关概念/语法与需求。
2. 我完成需求实现；实现过程中可随时向Copilot请求提示或排障支持。
3. Copilot执行订正：检查正确性与规范性，并说明问题原因。
4. 我根据订正意见修复实现；修复过程中可继续请求Copilot支持。
5. Copilot验证修复结果；若当前条目基本完成，则进入目录下一条。

期间，我会随时针对性向 Copilot 提问。

### 每一轮的交付格式

在进入目录某一条时，Copilot按固定格式发布任务：

1. 目标
2. 相关概念和语法
3. 本轮需求（由我实现）

我提交实现后，Copilot按固定维度反馈：

1. 正确性（功能是否满足需求、是否存在并发风险）
2. 规范性（命名、结构、异常与资源管理、注释质量）
3. 原因说明（为何需要修改，以及不修改的风险）
4. 修复清单（我下一步可直接执行的修改项）

期间，我会依照我的理解进行追问。
